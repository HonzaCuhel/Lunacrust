05 / FLIGHT CHECK

A little clarity
before liftoff.

An independent game, shared openly.
Here’s exactly where it stands.

Is the game actually ready?+

Ready for beta testing. The campaign, checkpoints, sprint, settings and local multiplayer have automated coverage, and desktop packages have passed native CI. A full survival run without injected resources, physical two-computer Wi-Fi and ordinary target-device testing still need validation. We’re calling this a release candidate, not a stable release.

What’s still rough around the edges?+

The Fabricator doesn’t yet show ingredients for unavailable recipes. For the first Stone Pickaxe, collect three rocks and two rods. Some in-game flight and respawn hints should say “Creative only.” The campaign’s pacing and first-time onboarding also need playtesting.

Can we play together in the browser?+

The browser demo is single-player. Desktop players on the same private Wi-Fi or wired network can open a world to LAN and join by discovery or host address. Everyone needs the same version. Guest Wi-Fi isolation or a firewall can prevent a connection.

Why aren’t the installers a one-click release yet?+

macOS and Windows candidates are unsigned, and macOS isn’t notarized, so the operating system can show a security approval prompt. Linux DEB installation was tested on Ubuntu 24.04 in CI; AppImage is built but hasn’t had a runtime launch check. Public releases remain drafts while those boundaries are made clear.

What do I need to play?+

A desktop keyboard, a mouse or trackpad, and WebGL2 graphics. Start with a lower render distance and resolution scale on integrated graphics. The website and trailer work on mobile; the game is designed for desktop input. Browser storage is local, so clearing site data removes browser saves.

Is it really open source?+

Yes. The game’s code and original artwork and music are under MIT, with separate notices for dependencies and fonts. Read the source, make changes, and help shape what comes next. Original branding and asset provenance are documented; that is not a formal trademark clearance.
