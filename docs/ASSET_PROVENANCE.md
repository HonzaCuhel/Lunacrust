## Changes made for an independent identity

The distributed title is **Lunacrust**. Removed the prior third-party game name from the title, package identity and marketing. Replaced the grass-block app icon with an original lunar navigation emblem. The two hostile aliens use original six-legged and tripod forms, names, palettes and animation rather than recognizable characters from another game. The HUD uses suit telemetry bars instead of heart/food silhouettes.

Exact-name web search for `"Lunacrust" game software trademark` returned no results on the audit date. This is a preliminary collision screen, not a search of every trademark register, territory, storefront or unregistered trade name. Trademark clearance remains an owner/legal review before committing to commercial branding.

General game ideas and methods can differ legally from their protected expression; copied artwork, code, text and recordings still require rights. See the [U.S. Copyright Office game guidance](https://www.copyright.gov/register/tx-games.html). Names also raise trademark issues distinct from copyright. The original [Minecraft usage guidelines](https://www.minecraft.net/en-us/usage-guidelines) do not grant this independent game permission to use that brand.
